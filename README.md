I’m a master’s student in bioinformatics at Capital Normal University. My thesis looks at genes that bumblebees inherited from transposable elements and where those genes are expressed in the brain. I also help maintain [iBumblebee](https://ngdc.cncb.ac.cn/ibumblebee/), a database for researchers working on bumblebees.
